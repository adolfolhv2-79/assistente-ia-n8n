# Privacidade e limites de divulgação

Este repositório destina-se exclusivamente à **apresentação técnica**. As informações aqui descritas são genéricas e derivadas da estrutura de um workflow privado.

## Não publicar

- Arquivos JSON originais exportados de workflows operacionais.
- Credenciais, tokens, senhas, chaves de API, variáveis de ambiente ou links internos.
- IDs de serviços, sessões, bancos, planilhas, webhooks e integrações.
- Dados de atendimento, nomes, telefones, documentos, histórico de conversa, áudios ou imagens de usuários.
- Prompts e regras internas específicas do cliente/organização.

## Antes de adicionar novos materiais

1. Confirmar autorização de quem é responsável pelo projeto.
2. Criar **exemplos sintéticos** a partir do zero, em vez de somente ocultar trechos de dados reais.
3. Revisar todos os arquivos e seu histórico de commits antes de tornar o repositório público.
4. Caso algum segredo seja publicado por engano, tratá-lo como comprometido e revogá-lo, além de corrigir o repositório.

A documentação existente não fornece código de implantação nem acesso ao ambiente real.
